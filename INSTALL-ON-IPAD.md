# Installing the Thai Boran Waiver app on the iPad

This is a plain-English guide for setting up the waiver app on the reception iPad.
No technical knowledge needed — just follow the steps in order.

The app lives at this web address (the "app link"):

**https://simmer80.github.io/thai-boran-waiver/**

> Always use **Safari** on the iPad (the built-in browser with the compass icon).
> Do not use Chrome or any other browser — only Safari can install it properly.

---

## 1. Remove the old app icon first

If there is already a "Thai Boran" icon on the Home Screen from before, remove it
so the iPad doesn't keep showing an old version.

1. Press and **hold your finger** on the old **Thai Boran** icon until the icons
   start to jiggle (or a small menu pops up).
2. Tap **Remove App** (or the **–** / minus in the corner of the icon).
3. Choose **Delete App**, then confirm **Delete**.

This only removes the shortcut and its saved copy of the app — it does **not**
touch any waiver records, because you are about to reinstall to the same place.
(But if this is a real iPad with real client data on it, export a backup first —
see section 4 — just to be safe.)

Press the **Home** button (or swipe up) to finish.

---

## 2. Install the app fresh

1. Open **Safari**.
2. Tap the address bar at the top and carefully type (or paste) the app link:
   **https://simmer80.github.io/thai-boran-waiver/**
   then tap **Go**.
3. Wait a few seconds for the waiver form to fully load.
4. Tap the **Share** button — the square with an arrow pointing up
   (top-right on most iPads, sometimes bottom).
5. In the list that appears, scroll down and tap **Add to Home Screen**.
6. It will suggest the name **Thai Boran** — leave it as is and tap **Add**
   (top-right).
7. A **Thai Boran** icon now appears on the Home Screen. **Close Safari.**
8. **Open the app by tapping that new Home Screen icon** — not from inside Safari.
   The first time it opens it may need an internet connection; after that it works
   offline.

---

## 3. Check you have the correct (newest) version

Open the app from the Home Screen icon and do these quick checks:

1. **Manager section has the new backup button.**
   - Tap **Manager Access** (top of the form).
   - Enter the **manager PIN** (the code the owner set) and tap **Unlock**.
   - On the **History** screen you should see three buttons:
     **Export CSV**, **Export Everything (ZIP)**, and **Clear Saved Data**.
   - If you can see **Export Everything (ZIP)**, you are on the current version. ✅
     (Older versions did not have this button.)

2. **Signature survives turning the iPad.**
   - On the waiver form, take a photo and sign in the signature box, then **rotate
     the iPad** between upright and sideways. The signature should **stay on
     screen** and not disappear. ✅

If either check fails, the iPad is probably still showing an old copy. Fix it by
repeating **Section 1** (remove the icon) and **Section 2** (reinstall). Making
sure the iPad is on Wi-Fi during reinstall helps it fetch the newest version.

> Tip for future updates: when a new version is released, just opening the app
> usually updates it within a moment or two (you may need to close and reopen it
> once). If you are ever unsure, remove the icon and reinstall — that always gets
> the latest version.

---

## 4. Clear the test data before going live

While testing, some practice waivers may have been saved. Clear them so the iPad
starts clean for real clients.

1. Open the app and tap **Manager Access**.
2. Enter the **manager PIN** and tap **Unlock**.
3. Make sure you are on the **History** tab.
4. **(Optional but recommended) Back up first:** tap **Export Everything (ZIP)**.
   This saves one file containing every record, photo, signature, the price list,
   and the sales history. Keep it somewhere safe. Skip this only if the data is
   just test rubbish you don't need.
5. Tap **Clear Saved Data**.
6. When it asks you to confirm, tap **OK / Clear**.
7. You should see a message that the data was cleared, and the History list is now
   empty.

> **Important:** Clearing is permanent — it erases **all** saved waivers, photos
> and signatures on the iPad. Only do this when you really mean to (like right
> before going live), and export a backup first if there is any chance you need
> the data later. The sales totals are kept as a summary even after clearing, so
> your revenue history is not lost.
